# Blind map 1: agent skills hubs (slice blind-1, 2026-10-14)

Method: about 26 web searches, no page fetches. Every row is from search snippets, so all numbers are third-party or self-reported and `verified` is null.

## Categories seen
- **Crawl-everything indexes:** SkillsMP, agentskill.sh, claude-plugins.dev (hourly GitHub crawl), LobeHub Skills, ClaudSkills, claudeskills.info. Huge counts, weak review.
- **Install-telemetry leaderboard:** skills.sh (Vercel). Rank = installs. Also has an audits page.
- **Curated or reviewed catalogues:** mdskills.ai (claims review per listing), Agensi (paid, scanned), Skills Directory (trust-first), claudemarketplaces.com (hand-curated, counts per listing), ethical.institute.
- **Vendor or first-party:** anthropics/skills, openai/skills (system, curated, experimental tiers), huggingface/skills, claude.com/connectors, Gemini CLI extensions.
- **Agent-specific registries:** ClawHub (OpenClaw), Smithery (skills plus MCP, CLI search), browse.sh (browser recipes).
- **Multi-type Claude Code catalogues:** aitmpl.com (agents, commands, hooks, MCP, settings; 1000+ components), localskills.sh (accounts, versions, teams).
- **Cursor rules:** cursor.directory, CursorList, awesome-cursorrules (PatrickJS, CC0, .mdc format), a 879-file .mdc conversion.
- **Awesome lists (GitHub):** hesreallyhim/awesome-claude-code, ComposioHQ/awesome-claude-skills, travisvn, VoltAgent, karanb192 (verified ticks), BehiSecc (via Context Awesome).
- **Standard and meta:** agentskills.io (spec, not a catalogue), agenticskills.io comparison table, Context Awesome.
- **Legacy consumer:** GPT Store (chatgpt.com/gpts), leaderboard plus categories.
- **AGENTS.md examples:** ossrules.md, agents.md project's 60k+ claim, GitHub's 2,500-repo analysis (blog, not a row).

## UI patterns observed
- Cards with install count and star count (claudemarketplaces, claudeskills.info, LobeHub).
- Leaderboards by installs or 24h trend (skills.sh), or by community popularity (GPT Store).
- Category grids with counts (claudeskills.info 61 categories; claudemarketplaces by topic).
- Copyable install command per item (`npx skills add`, `/plugin install x@marketplace`, `openclaw skills install`, `smithery skill search`).
- Security badges: OWASP-graded scan (ClaudSkills), audits page (skills.sh), "Skill Advisor" review (mdskills).
- Search with facets: category, install count, rating (LobeHub), keyword/occupation/creator/source (SkillsMP).
