# Web UI assignment

Attach the private `sisodias/siso-harness-lab` repository and use the branch
containing this file. This requires repository access and a code execution
environment; a chat-only session cannot run or persist the loop by itself.

Paste this assignment:

> Own the next bounded efficiency-improvement cycle in this repository. Read
> AGENTS.md, .agents/PAGE.md, .agents/HANDOFF.md and docs/IMPROVEMENT-LOOP.md.
> Run npm run project:status, npm test and npm run loop:check. Use the existing backlog
> and source-linked reports; do not repeat a whole-history audit. Reproduce one
> concrete failure, make the smallest causal correction, test counterexamples and
> a fresh held-out case, record both gains and failures, update the handoff and
> commit the verified work. Continue to the next unblocked experiment while the
> assigned session budget permits. Do not stop at a plan while safe scoped work
> remains. If blocked, record the exact missing input and choose another unblocked
> existing item. Do not fabricate measurements or infer laptop access. Never
> restart live agents, change providers or global safety rules, upload raw logs,
> schedule compute or create an agent swarm as a side effect.

No API key or package installation is needed for the seed offline experiment.
For new model-backed tests, use an explicitly approved runtime and budget; do not
invent credentials or treat fixture results as model-behavior proof.
